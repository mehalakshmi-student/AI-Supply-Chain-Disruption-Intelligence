AI-Powered Supply Chain Disruption Intelligence & Early Warning System

Project Overview

This project analyzes supply chain shipment data and identifies potential disruption risks using Machine Learning. It provides an interactive dashboard and business recommendations to support decision-making.

Objectives

- Analyze supply chain performance.
- Identify shipment disruption risks.
- Analyze supplier performance.
- Understand weather and transportation impacts.
- Provide early warning indicators.
- Support business decisions with data.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Plotly
- Scikit-learn
- Streamlit
- GitHub

Key Features

- Interactive dashboard
- Shipment risk classification
- Supplier performance analysis
- Weather impact analysis
- Transportation cost analysis
- Business recommendations
- CSV report generation

Machine Learning

Random Forest Classifier is used for shipment disruption risk classification.

Dataset

This prototype uses a synthetically generated shipment dataset for demonstration and testing. Model results should not be interpreted as validated real-world predictions.

Project Files

- "app.py" – Streamlit application
- "supply_chain_dataset.csv" – Shipment dataset
- "supply_chain_risk_model.pkl" – Trained model
- "model_columns.pkl" – Model feature columns
- "requirements.txt" – Required libraries
- CSV files – Analysis reports

How to Run

pip install -r requirements.txt
streamlit run app.py
